# Security policy

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/syntel-technologies/symba-sdk-python/security/advisories/new). Do not disclose credentials or exploitable details in a public issue.

During the initial pre-1.0 release period, fixes target the latest release line. No older-version support window or response-time guarantee is implied. Maintainers assess reports, coordinate a fix and publish an advisory when appropriate.
